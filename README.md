# TideBites — Content-only update

A playful summer-wave virtual restaurant concept for college students. Catch a Wave of Flavor!

Open root index.html in Chrome. No build or npm is required. The original W3.CSS, Google Fonts and Font Awesome links remain and require internet for their external resources.

Content: ten original food photographs transferred unchanged from the reference feature branch, menu names, descriptions, categories, proposed prices, brand copy, About, features, editorial favorites, student deals, FAQ and footer.
